# dotfiles

Hyprland rice on Arch: dark, red accent, JetBrainsMono Nerd Font.

- `hyprlock/` terminal-style lock screen
- `sddm-terminal/` login screen theme (copy to /usr/share/sddm/themes/terminal and add your own bg.png)
- `waybar/` bar config and style (see also the standalone waybar-terminal repo)
- `sync.sh` copies the live configs here, commits and pushes

Runs on top of [JaKooLit's Hyprland-Dots](https://github.com/JaKooLit/Hyprland-Dots).
